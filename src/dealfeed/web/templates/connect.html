Claude Code

Adds Deal Feed as a remote MCP server. Replace the key with one of yours.

claude mcp add --transport http dealfeed {{ mcp_url }} \
  --header "Authorization: Bearer {{ new_key or 'dfk_your_key_here' }}"

Claude Desktop (runs on your computer)

Add to claude_desktop_config.json. This runs the server locally against your own database, so it's for your own use, not for customers.

{
  "mcpServers": {
    "dealfeed": {
      "command": "/path/to/.venv/bin/dealfeed",
      "args": ["serve-mcp", "--transport", "stdio"],
      "env": {
        "DATABASE_URL": "{{ db_url_hint }}",
        "DEALFEED_LOCAL_USER": "{{ user.email }}"
      }
    }
  }
}
