Claude Code

Adds Deal Feed as a remote MCP server. Create a key on the right, then run:

claude mcp add --transport http dealfeed {{ mcp_url }} \
  --header "Authorization: Bearer {{ new_key or 'dfk_your_key_here' }}"

Claude Desktop Runs locally

Add to claude_desktop_config.json. This runs the server on your computer against your own database, so it's for your own use, not for customers.

{
  "mcpServers": {
    "dealfeed": {
      "command": "/path/to/.venv/bin/dealfeed",
      "args": ["serve-mcp", "--transport", "stdio"],
      "env": {
        "DATABASE_URL": "{{ db_url_hint }}",
        "DEALFEED_LOCAL_USER": "{{ user.email }}"
      }
    }
  }
}

REST API

For your own scripts and CRM. Results cost 1 credit per business, once a month.

curl -X POST {{ request.base_url }}v1/targets/search \
  -H "Authorization: Bearer {{ new_key or 'dfk_your_key_here' }}" \
  -H "Content-Type: application/json" \
  -d '{"industry": "pest control", "min_years_in_business": 20}'
